# EA Creative Engine

Sistema de automação gráfica da E&A Personalizados.

## Objetivo

Criar, padronizar e gerar artes em massa utilizando templates estruturados, assets, datasets e renderização automática.

## Arquitetura

- Frontend: React + TypeScript + Vite
- Backend: Supabase
- Banco: PostgreSQL
- Storage: Supabase Storage
- Deploy: Vercel
- Render Worker: Node.js

## Módulos principais

- Templates
- Assets
- Brand Kits
- Produtos
- Datasets
- Geração em massa
- Render Queue
- Histórico e auditoria
